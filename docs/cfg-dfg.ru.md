# CFG и DFG

Первый PR добавляет в граф рёбра потока управления (CFG) и потока данных (DFG). Для них предусмотрены проходы в пакете `analysis` и отдельные цвета в SVG.

## Границы анализа

Каждая функция или метод анализируется отдельно. В выражении `int y = f(x);` DFG показывает передачу значения `x` в вызов и использование результата для инициализации `y`. Существующая ссылка вызова на объявление `f` сохраняет своё назначение. Межпроцедурные связи «аргумент → формальный параметр» и «return вызываемой функции → вызов» отложены.

## Детализация CFG

Вершинами потока управления служат исполняемые инструкции и выражения условий целиком. В конструкции `if (x > 0) y = a + b;` ребро `true` ведёт от условия к инструкции присваивания, а ребро `false` — к следующей инструкции после `if`, если она есть. Чтение отдельных операндов и сложение внутри инструкции отражаются на уровне зависимостей DFG.

## Записи, достигающие чтения

Для каждого чтения локальной переменной DFG содержит ребро от каждой записи в эту переменную, которая достигает чтения хотя бы по одному пути CFG без перезаписи. При слиянии ветвей множества таких записей объединяются.

В примере `int x = 0; if (flag) x = 1; else x = 2; int y = x;` к последнему чтению `x` ведут рёбра от присваиваний `x = 1` и `x = 2`. Обе ветви перезаписывают начальное значение. Если убрать ветвь `else`, по ложной ветви до чтения дойдёт инициализация `int x = 0`.
