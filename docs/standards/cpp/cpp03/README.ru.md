# C++03 — базовая редакция для парсера

Целевая спецификация — **ISO/IEC 14882:2003, Programming languages — C++**, второе издание. При расхождении формулировок для режима C++03 определяющим является текст этого издания. [Карточка ISO](https://www.iso.org/standard/38110.html).

Исторический справочный материал — [рабочий проект WG21 N1638 на сайте комитета](https://www.open-std.org/jtc1/sc22/wg21/docs/papers/2004/n1638.pdf), 772 страницы, **от 11 апреля 2004 года**, уже после публикации C++03. В [редакторском отчёте N1578](https://www.open-std.org/jtc1/sc22/wg21/docs/papers/2004/n1578.html) редакторы указывают ISO/IEC 14882:2003 как исходную редакцию для N1577 и описывают внесённые поправки. [Отчёт N1639](https://www.open-std.org/jtc1/sc22/wg21/docs/papers/2004/n1639.html) перечисляет дальнейшие изменения для N1638. Поэтому для спорного теста парсера важно проверить, присутствовало ли правило уже в C++03.

В PDF можно искать по коротким обозначениям разделов: `[lex]` — лексика, `[expr]` — выражения, `[stmt]` — инструкции, `[dcl.dcl]` — объявления, `[dcl.fct]` — деклараторы функций.
