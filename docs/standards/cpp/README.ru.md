# Спецификация C++

Разработку расширенного подмножества начинаем с **C++03**. [Карточка базовой редакции, локальный PDF рабочего проекта и различия между документами](cpp03/README.ru.md).

Для правил опубликованного C++23 (ISO/IEC 14882:2024) используем **N4950**. Для конструкций C++26 используем **N5050**. Это зафиксированные исходные тексты редакторов WG21, из которых собираются полные рабочие проекты стандарта. Официальное издание ISO имеет собственную карточку публикации.

| Редакция | Полный текст в репозитории | PDF комитета | Основание выбора |
|---|---|---|---|
| C++23 | [cpp23](cpp23) · [ревизия редакторов](https://github.com/cplusplus/draft/tree/4e4de1df8ee941255b653b61d0a62050b34cf8c9) | [N4950](https://open-std.org/jtc1/sc22/wg21/docs/papers/2023/n4950.pdf) | [N4951](https://open-std.org/jtc1/sc22/wg21/docs/papers/2023/n4951.html) называет N4950 финальным рабочим проектом C++23. [Карточка ISO/IEC 14882:2024](https://www.iso.org/standard/83626.html). |
| C++26 | [cpp26](cpp26) · [ревизия редакторов](https://github.com/cplusplus/draft/tree/8ab1a9b574d97fea3809a2885c7f41f5d60b93f6) | [N5050](https://open-std.org/jtc1/sc22/wg21/docs/papers/2026/n5050.pdf) | По [N5051](https://open-std.org/jtc1/sc22/wg21/docs/papers/2026/n5051.html), это финальный рабочий проект C++26 и основа текста для голосования ISO (DIS). |

На 4 ноября 2026 года работу редакторов уже продолжает линия C++29. Например, [N5055](https://open-std.org/jtc1/sc22/wg21/docs/papers/2026/n5055.html) относит N5054 к C++29. Поэтому ссылки на разделы при разработке парсера привязываем к конкретной редакции.

## Локальное чтение

Из корня уже клонированного CPG выполни один раз:

```sh
git submodule update --init --depth 1 -- docs/standards/cpp/cpp23 docs/standards/cpp/cpp26
```

После этого оба текста доступны без сети. При новом клонировании можно сразу использовать `git clone --recurse-submodules`. В каждой папке файл `source/std.tex` задаёт структуру документа. Для синтаксиса удобны именованные разделы, например `[stmt.if]`, `[expr.assign]`, `[dcl.fct]`. Пример поиска:

```sh
rg -n -F '[stmt.if]' docs/standards/cpp/cpp26/source
```

Если нужен свёрстанный документ, проще открыть PDF из таблицы. Для самостоятельной сборки в каждой ревизии есть инструкция в `README.rst`. Подмодули указывают на внешний репозиторий `cplusplus/draft`; лицензия MIT проекта CPG относится к собственному коду CPG.
